راهنمای نصب Nulvar core برای اولین بار
======================================

این بسته شامل سورس کامل، نسخه Production، فایل نصب و اجرا، آیکون‌ها و تنظیمات PWA است.

مرحله ۱ — خارج کردن فایل ZIP
--------------------------------
روی فایل Nulvar-core-Complete-Package.zip راست‌کلیک کنید و Extract All را بزنید.
بهتر است پوشه را در مسیر ساده‌ای مثل زیر قرار دهید:

C:\Nulvar-core

برنامه را مستقیماً از داخل فایل ZIP اجرا نکنید.

مرحله ۲ — نصب Node.js
----------------------
اگر Node.js روی سیستم نصب نیست:

1. وارد https://nodejs.org شوید.
2. نسخه LTS را دانلود و نصب کنید.
3. هنگام نصب، تنظیمات پیش‌فرض و گزینه Add to PATH را نگه دارید.
4. پس از نصب، پنجره‌های Command Prompt را ببندید.

فایل Nulvar-Core.bat نیز نبودن Node.js را تشخیص می‌دهد و می‌تواند صفحه دانلود را باز کند.

مرحله ۳ — نصب اولیه Nulvar
---------------------------
1. وارد پوشه Extractشده شوید.
2. روی Nulvar-Core.bat دوبار کلیک کنید.
3. گزینه 1 یعنی First install / repair dependencies را انتخاب کنید.
4. صبر کنید تا پیام موفقیت نمایش داده شود.

این مرحله فقط بار اول یا هنگام تعمیر برنامه لازم است و ممکن است چند دقیقه طول بکشد.

مرحله ۴ — اجرای روزانه
-----------------------
1. دوباره Nulvar-Core.bat را اجرا کنید.
2. گزینه 2 یعنی Start development mode را بزنید.
3. مرورگر خودکار روی آدرس http://localhost:5173 باز می‌شود.
4. پنجره مشکی را تا وقتی با برنامه کار می‌کنید نبندید.
5. برای توقف برنامه داخل پنجره مشکی Ctrl+C بزنید.

مرحله ۵ — نصب مثل اپ ویندوز
----------------------------
پس از بازشدن Nulvar در Edge یا Chrome:

1. وارد تنظیمات Nulvar شوید.
2. دکمه «نصب روی این دستگاه» را بزنید.
3. در صورت نمایش پیام مرورگر، Install را تأیید کنید.

بعد از نصب، آیکون گرگ Nulvar در Start Menu و Desktop قابل دسترسی خواهد بود.
توجه: برای استفاده از نسخه محلی، Nulvar-Core.bat و سرور محلی باید در حال اجرا باشند.
اگر برنامه را روی GitHub Pages منتشر کنید، دیگر نیازی به روشن‌بودن سرور محلی نیست.

موبایل
------
Android / Chrome:
Menu > Install app

iPhone / Safari:
Share > Add to Home Screen

برای نصب روی موبایل باید نسخه GitHub Pages یا یک آدرس HTTPS قابل دسترسی را باز کنید؛ آدرس localhost کامپیوتر روی موبایل کار نمی‌کند.

اطلاعات من کجا ذخیره می‌شود؟
-----------------------------
اطلاعات در IndexedDB همان مرورگر ذخیره می‌شود. پاک‌کردن داده‌های سایت یا حذف پروفایل مرورگر ممکن است اطلاعات را پاک کند.
از بخش تنظیمات Nulvar مرتب فایل پشتیبان JSON بگیرید.

به‌روزرسانی یا تعمیر
-------------------
در Nulvar-Core.bat:
- گزینه 3: تست و ساخت نسخه Production
- گزینه 4: پیش‌نمایش Production
- گزینه 5: اجرای تست‌ها
- گزینه 6: حذف و نصب تمیز وابستگی‌ها

مشکلات رایج
------------
1. پیام node is not recognized:
   Node.js LTS را نصب کنید و سیستم یا Command Prompt را دوباره باز کنید.

2. صفحه باز نمی‌شود:
   مطمئن شوید پنجره Nulvar-Core.bat باز است و آدرس http://localhost:5173 را دستی وارد کنید.

3. پورت 5173 اشغال است:
   برنامه‌های قبلی Node را ببندید و دوباره اجرا کنید.

4. اطلاعات نمایش داده نمی‌شود:
   همان مرورگر و همان پروفایل قبلی را استفاده کنید و فایل پشتیبان را بررسی کنید.

نکته امنیتی
------------
کلید API محرمانه را داخل تنظیمات مرورگر یا فایل‌های VITE قرار ندهید. برای مدل محلی فقط endpoint مورد اعتماد خودتان را وارد کنید.
